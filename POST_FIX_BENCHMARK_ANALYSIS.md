## Technical Deep Dive: Why Test Videos Were Already Correct

### Test Video Generator Implementation

```python
# tools/make_mp4_testset.py lines 48-60
def _draw_gaussian_beacon(frame, cx, cy, radius_px, peak):
    H, W = frame.shape[:2]
    sigma = radius_px / 2.5
    r = max(1, int(radius_px * 3))
    x0, x1 = max(0, int(cx) - r), min(W, int(cx) + r + 1)
    y0, y1 = max(0, int(cy) - r), min(H, int(cy) + r + 1)
    
    # ✅ CRITICAL: cx, cy are FLOAT, not quantized
    xs = np.arange(x0, x1, dtype=np.float32) - cx  # Sub-pixel offset
    ys = np.arange(y0, y1, dtype=np.float32) - cy  # Sub-pixel offset
    xx, yy = np.meshgrid(xs, ys)
    g = np.exp(-(xx**2 + yy**2) / (2 * sigma**2))  # Gaussian from float center
```

### Simulator Implementation (BEFORE P0.9 Fix)

```python
# src/environment/beacon.py (OLD CODE)
def draw(self, image: np.ndarray, offset_x: float, offset_y: float):
    draw_x = int(round(self.x - offset_x))  # ❌ QUANTIZATION BUG
    draw_y = int(round(self.y - offset_y))  # ❌ QUANTIZATION BUG
    
    # Gaussian computed from INTEGER center (wrong)
    Y, X = np.ogrid[y_min:y_max, x_min:x_max]
    dist = ((X - draw_x)**2) / (2 * sigma_x**2) + ...
```

### Simulator Implementation (AFTER P0.9 Fix)

```python
# src/environment/beacon.py (NEW CODE)
def draw(self, image: np.ndarray, offset_x: float, offset_y: float):
    draw_x = self.x - offset_x  # ✅ Float preserved
    draw_y = self.y - offset_y  # ✅ Float preserved
    
    # ✅ NOW MATCHES TEST VIDEO GENERATOR
    xs = np.arange(x_min, x_max, dtype=np.float32) - draw_x
    ys = np.arange(y_min, y_max, dtype=np.float32) - draw_y
    X, Y = np.meshgrid(xs, ys)
    dist = (X**2) / (2 * sigma_x**2) + (Y**2) / (2 * sigma_y**2)
```

**Conclusion:** Test video generator was already correct. P0.9 fix brings simulator rendering to match it.
